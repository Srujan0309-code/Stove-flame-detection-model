Stove Flame Detection using YOLOv8 🔥
A real-time stove flame detection system built using YOLOv8 and trained on a custom dataset using Google Colab GPU acceleration.
This project detects burning and non-burning stove conditions using computer vision and deep learning techniques.

🚀 Features


Real-time flame detection
YOLOv8 object detection model
Custom-trained dataset
High-speed inference
GPU-based training using Google Colab
Edge AI deployment ready
Compatible with YOLOvX/WISERLI deployment platform

🧠 Technologies Used
Python
YOLOv8 (Ultralytics)
OpenCV
PyTorch
Google Colab
Roboflow
Computer Vision
